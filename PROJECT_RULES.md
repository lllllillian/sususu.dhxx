# StoryForge Writing Workshop Project Rules

Use this document as the highest standard for all future work on StoryForge Writing Workshop.

## Product Purpose

Build and revise the website as a local demo for senior high school English continuation writing. The interface should be primarily Chinese for student guidance and classroom use, while English source passages, phrases, and writing examples may remain in English where they support English learning.

## Primary Audience

Prioritize the student experience. Teacher tools should support assignment setup, feedback, rubric-based correction, and anonymous gallery approval without turning the product into a corporate dashboard.

## Confirmed Learning Flow

Preserve this learning flow:

1. Reading understanding and mind map
2. Outline building
3. Role perspective selection
4. Continuation drafting
5. Class expression bank
6. Student self-assessment
7. Teacher feedback
8. Anonymous approved gallery

Student self-assessment and teacher evaluation must remain separate systems.

## Visual Direction

The visual style should feel like a creative writing workshop:

- Soft
- Retro
- Hand-drawn
- Gently glowing
- Exploratory
- Interesting but not childish
- Never visually harsh

Reference images may inform mood only. Do not copy their text, objects, or layouts.

## Avoid

Avoid:

- Corporate dashboard patterns
- Exam-drill pages
- Neon game styling
- Clutter
- Decorative elements that do not support writing learning
